# Seven Nil

Play the game: [seven-nil-self.vercel.app](https://seven-nil-self.vercel.app)

World Cup and club draft XI by nik.peeps. Roll a squad, pick eleven, simulate the campaign.

- [World Cup draft](https://seven-nil-self.vercel.app/): historic national teams
- [Club draft](https://seven-nil-self.vercel.app/club): top-five league sides from 1980 on
- [Friends](https://seven-nil-self.vercel.app/friends): local, Cup Final, Full Cup
- [How to play](https://seven-nil-self.vercel.app/how-to-play)

```bash
npm install
npm run dev
```

Production: `npm run build`

## Deploy on Vercel

The repo is already on GitHub. **Import it** — do not clone a second copy.

1. Install the Vercel GitHub App on this account:  
   [github.com/apps/vercel/installations/new](https://github.com/apps/vercel/installations/new)  
   Allow **sagnikdhar2018-jpg** (all repos, or at least `seven-nil`).
2. Import the existing repo:  
   [vercel.com/new/import?s=https://github.com/sagnikdhar2018-jpg/seven-nil](https://vercel.com/new/import?s=https://github.com/sagnikdhar2018-jpg/seven-nil)
3. Team: **sagnikdhar2018-jpg's projects**. Click **Deploy**.

After that, every push to `main` goes live automatically.

Do **not** use the “Clone” / “Create a Git repository” screen. That flow is greyed out until GitHub is selected and it would duplicate the repo.
